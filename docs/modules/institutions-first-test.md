# Primera prueba modular de Institutions — v11.35

La documentación y configuración se concentran en
`app/Modules/Institutions/README.md` y `Configuration/`.

La prueba incluye General, Contacto y Usuarios relacionados; permite abrir el mismo
formulario de Usuario desde la relación, con validación y guardado automático.
La estructura de pestañas se cambia en PHP. El diseñador visual se desarrollará
después de comprobar este modelo.

Prueba el cambio de pestañas, la X, el guardado, la búsqueda de usuarios y su
formulario, así como el modo móvil. Esta versión no necesita npm build ni agrega
una migración nueva respecto a v11.34.
